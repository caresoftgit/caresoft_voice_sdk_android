# Changelog

## 1.0.0 — 2026-11-12

- SDK Android native với Kotlin suspend API và callback Java; đăng nhập/khôi phục phiên, trạng thái nhân viên, thiết bị nhận và đầu số gọi ra.
- Gọi đi/nhận cuộc gọi, kết thúc, mute/hold phía server, DTMF và WebRTC statistics.
- Self-managed Telecom, audio focus, chuyển loa theo callback hệ thống và FCM bridge cho host.
- UI cuộc gọi tùy chọn và demo đăng nhập/bàn phím/cuộc gọi với hai chế độ UI.
- Bàn giao Maven binary/AAR, APK thử, ví dụ Kotlin/Java và tài liệu tích hợp. Không kèm cấu hình môi trường thử hoặc source SDK.
